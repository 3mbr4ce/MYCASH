MYCASH 0.0.1 for Windows (part of MYSUITE)

Debts and monthly cash flow: keep every debt with its remaining balance, plan this month's payments,
income, living costs and subscriptions, and see the surplus or shortfall at once.

Your data: %LOCALAPPDATA%\MYCASH\data (data.json, a backup copy data.json.bak, sync.json = paired devices).
Uninstalling keeps it unless you tick "Delete my data too".

Sync with the MYCASH phone app: same Wi-Fi/LAN, MYCASH open on both, Sync tab -> Show pairing code on one
device, Scan code (phone) or Enter pairing text on the other, then type the 6-digit code. Only your local
network is used (TCP port 47870), never the internet. Allow MYCASH on private networks if Windows asks.

Needs the Microsoft Edge WebView2 Runtime (preinstalled on Windows 11 and most Windows 10 PCs).
